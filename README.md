# ◆ AssetFlow

### Cadastro e Gestão de Ativos de TI

**AssetFlow** é uma interface moderna para cadastro de ativos de TI, desenvolvida para simplificar o registro, identificação, atribuição e acompanhamento de equipamentos de uma empresa.

O projeto combina um **fluxo profissional de gerenciamento de ativos de TI** com uma interface tática inspirada em HUDs de jogos competitivos, criando uma experiência visual diferenciada sem depender de frameworks pesados.

## 🎯 Sobre o Projeto

O AssetFlow foi desenvolvido como uma solução leve para **equipes de Suporte Técnico e departamentos de TI** que precisam registrar e organizar equipamentos corporativos.

A aplicação tem como foco o processo inicial de entrada de ativos, permitindo registrar informações importantes sobre um equipamento e sua atribuição.

### Conceito

**TI Corporativa × Interface Tática**

Em vez de seguir o padrão visual tradicional de sistemas administrativos, o AssetFlow utiliza elementos visuais inspirados em interfaces táticas e HUDs, mantendo uma experiência profissional e funcional.

## ⚡ Funcionalidades

### Cadastro de Ativos

- Cadastro de equipamentos de TI
- Identificação do ativo

### Interface

- Layout responsivo
- Interface escura e tática
- Hierarquia visual clara
- Estados interativos dos formulários

## 🛠️ Tecnologias

O AssetFlow utiliza uma stack simples e leve.

- **HTML5** — estrutura da aplicação
- **CSS3** — layout, responsividade e identidade visual
- **JavaScript** — interações e lógica dos formulários
- **Google Fonts** — tipografia

### Sem Framework

O projeto não depende de React, Vue, Angular, Bootstrap, Tailwind ou outros frameworks de frontend.

Isso mantém a aplicação:

- Leve
- Rápida
- Fácil de entender
- Fácil de modificar
- Simples de hospedar
